# JavaScript Grocery Store

A simple client-side grocery store app with a product catalog and shopping cart. Built with HTML, CSS, and JavaScript.

## Features
- Browse a catalog of grocery items
- Add/remove items from the shopping cart
- View cart total

## Usage
Open `index.html` in your browser to use the app.

## Project Structure
- `index.html` — Main HTML file
- `style.css` — Basic styling
- `src/app.js` — App logic

## No backend required
All logic is client-side only.
